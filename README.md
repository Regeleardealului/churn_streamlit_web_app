# Customer Churn Prediction 🚀

## Overview
This project aims to predict customer churn in the telecom industry using deep learning techniques. By leveraging a Kaggle dataset, I built a predictive model and deployed it as a user-friendly web application using Streamlit.

## 🔍 Project Highlights
- **Data Preprocessing & EDA**: Cleaned, preprocessed, and explored the dataset using Python to uncover key insights.
- **Modeling**: Trained a Neural Network designed for accurate customer churn prediction.
- **Deployment**: Developed and deployed an interactive web application with Streamlit.

## 📊 Dataset
The dataset used for this project is sourced from Kaggle and contains customer information, contract details, and service usage data. The target variable is customer churn status.

## 🔧 Technologies Used
- Python 🐍
- Pandas & NumPy for data manipulation
- Matplotlib & Seaborn for data visualization
- Scikit-learn for feature engineering
- TensorFlow/Keras for deep learning
- Streamlit for web app deployment

## 🚀 How to Run Locally
1. Clone this repository:
   ```bash
   git clone https://github.com/yourusername/Customer-Churn-Prediction.git
   cd Customer-Churn-Prediction
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the Streamlit app:
   ```bash
   streamlit run app.py
   ```
